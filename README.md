# Книжная полка

Учебный сайт книжного магазина на React. Сделан как практическая работа по МДК 01.06 «Web-программирование».

На сайте можно посмотреть каталог книг, найти нужную по названию или автору, отфильтровать по жанру и открыть страницу с описанием. После регистрации появляется личный кабинет: там можно поменять имя и посмотреть книги, которые вы добавили в избранное.

Сервера у проекта нет. Пользователи, текущая сессия и избранное хранятся в `localStorage` браузера. Пароли там лежат открытым текстом, так что это только учебная имитация, для настоящего сайта так делать нельзя.

## Как запустить

Нужен Node.js (я проверял на 24-й версии).

```bash
npm install
npm run dev
```

После этого сайт откроется по адресу http://localhost:5173.

Другие команды:

- `npm run build` собирает готовую версию сайта в папку `dist/`
- `npm run preview` запускает эту собранную версию, чтобы проверить её перед публикацией
- `npm run lint` проверяет код линтером

## Что есть на сайте

| Адрес | Страница |
| --- | --- |
| `/` | Главная, на ней четыре самые популярные книги |
| `/catalog` | Каталог с поиском и фильтром по жанрам |
| `/catalog/:id` | Страница одной книги |
| `/register` | Регистрация |
| `/login` | Вход |
| `/account` | Личный кабинет, раздел «Профиль» (только для вошедших) |
| `/account/favorites` | Личный кабинет, раздел «Избранное» (только для вошедших) |
| любой другой адрес | Страница 404 |

## Как проверить

1. Зарегистрируйтесь. Форма не пропустит пустое имя, email без `@` и точки, пароль короче 6 символов и разные пароли в двух полях.
2. После регистрации сайт сам переведёт вас в личный кабинет, а в шапке вместо «Войти» появится ваше имя и кнопка «Выйти».
3. Зайдите в каталог и отметьте пару книг сердечком. Они появятся в разделе «Избранное».
4. Обновите страницу (F5). Вы останетесь в аккаунте, избранное тоже сохранится.
5. Нажмите «Выйти» и попробуйте открыть `/account`. Сайт отправит вас на страницу входа, а после входа вернёт обратно.
6. Введите неверный пароль, и появится сообщение об ошибке.

## Как устроен проект

```
src/
  components/   переиспользуемые куски интерфейса
  pages/        страницы, на каждую свой маршрут
  context/      AuthContext, где хранится, кто сейчас вошёл
  hooks/        useFavorites, работа с избранным
  data/         список книг и имитация загрузки с сервера
  App.jsx       все маршруты сайта
  main.jsx      точка входа, здесь подключаются роутер и AuthContext
  index.css     все стили
```

Немного о том, где что искать:

- **Маршруты** описаны в `App.jsx`. Шапка и подвал общие для всех страниц, поэтому они вынесены в `Layout`, а страницы подставляются внутрь через `<Outlet />`. Личный кабинет тоже сделан вложенными маршрутами: «Профиль» и «Избранное» отрисовываются внутри `Account`.
- **Защита страниц**: `ProtectedRoute` проверяет, вошёл ли пользователь. Если нет, перенаправляет на `/login` и запоминает, куда человек хотел попасть.
- **Авторизация** живёт в `context/AuthContext.jsx`. Там регистрация, вход, выход и смена имени. Текущий пользователь сохраняется в `localStorage` через `useEffect`, поэтому сессия переживает перезагрузку страницы.
- **Каталог** (`pages/Catalog.jsx`) загружает книги в `useEffect`, пока идёт загрузка, показывает `Loader`. Поиск и фильтр хранятся в `useState`, а подходящие книги отбираются из общего списка прямо при отрисовке.
- **Переиспользуемые компоненты**: `BookCard` и `BookList` используются на главной, в каталоге и в избранном, `Button` встречается почти везде, `FormField` нужен в регистрации, входе и профиле, `Loader` показывается в каталоге и на странице книги.
- **Анимации**: страницы и карточки плавно появляются, карточки приподнимаются при наведении, мобильное меню выезжает с анимацией. Всё сделано на CSS в `index.css`.
- **Адаптивность**: на экранах уже 768px меню прячется под кнопку-бургер, а страница книги и личный кабинет выстраиваются в одну колонку.
